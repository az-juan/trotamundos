# Actores
+ Usuarios (móvil y web)
+ Aplicaciones externas de transportes y alojamientos
+ Agencias de viajes y hospedaje
+ Mail provider
+ Analistas de datos
+ Proveedores de redes sociales

# Functional requirements

- FR-1: El usuario debe poder ver todas sus reservas (hospedaje y transporte) existentes cruzando info de diferentes apps (APIs estandar).
- FR-2: El sistema debe estar conectado con email para capturar automaticamente las reservas.
- FR-3: El sistema debe permitir crear whitelists de remitentes seguros.
- FR-4: El usuario debe poder realizar una gestion manual de reservas.
- FR-5: El sistema debe permitir tener elementos de viaje agrupados por viaje, y debe archivarlos automaticamente una vez que el viaje se completó.
- FR-7: El sistema deberá recompilar datos analíticos de los viajes de sus usuarios.
- FR-8: El usuario debe poder compartir su itinerario a traves de redes sociales./
