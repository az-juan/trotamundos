# Actores
+ Usuarios (móvil y web)
+ Aplicación externa de viajes
+ Agencias de viajes
+ Mail provider
+ Analistas


- FR-1: El usuario debe poder ver todas sus reservas (hospedaje y transporte) existentes cruzando info de diferentes apps (APIs estándar).
- FR-2: El sistema debe estar conectado con email para capturar automáticamente las reservas.
- FR-3: El sistema debe permitir crear whitelists de remitentes seguros.
- FR-4: El usuario debe poder realizar una gestión manual de reservas.
- FR-5: El sistema debe permitir tener elementos de viaje agrupados por viaje, y debe archivarlos automáticamente una vez el viaje esté completo.
- FR-6: La app/web debe redirigir automáticamente al usuario a apps de terceros cuando estos soliciten operar sobre sus reservas, viajes, atención al cliente.
- FR-7: El sistema deberá recompilar datos analíticos de los viajes de sus usuarios.
- FR-8: El usuario debe poder compartir su itinerario a través de redes sociales.
- FR-9: El sistema debe monetizar la plataforma a partir de la analítica de datos agregados de viajes (tendencias de destinos, demanda y patrones de cancelación), ofreciéndola como insight comercial a terceros (aerolíneas, hoteles, destinos turísticos).
