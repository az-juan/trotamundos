## ADR-011: Mobile Nativo (Swift + Kotlin)

**Status**: Propuesto
**Fecha**: 2026-10-26
**Decidido por**: Equipo de arquitectura

### Contexto

La app móvil debe: aprovechar GPS nativo (proximidad a aeropuerto/estación), push notifications, y cumplir FCP < 1.4 s. Se evaluaron: React Native, Flutter, y nativo.

### Decisión

- **iOS**: Swift + SwiftUI + MVVM. `DIContainer` manual (sin Swinject). `URLSession` + `WebSocket` para live updates.
- **Android**: Kotlin + Jetpack Compose + MVVM + Hilt (DI). `Retrofit` + `OkHttp` para API. `WorkManager` para sync en segundo plano.

Ambos consumen la misma API REST del Gateway (OpenAPI como contrato).

### Consecuencias

| Positivas | Negativas / Riesgos |
|-----------|-------------------|
| GPS, push, notificaciones: acceso nativo directo sin bridges | 2 codebases (mitigado: mismo contrato OpenAPI, mismos modelos de datos) |
| FCP < 1.4 s garantizado (sin JS bridge) | Equipo debe tener devs iOS y Android (mitigado: en Fase 0, solo 1 plataforma; la segunda en Fase 1) |
| Performance en picos (500K notificaciones de disrupción): native push, no JS | |
